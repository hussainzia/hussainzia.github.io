My personal website, hosted on GitHub Pages at **https://hussain1847.github.io/**.

## ✨ Features

- **Animated robotic-arm hero** drawn in SVG and animated with CSS
- **Focus areas:** embedded systems, robotics, mechatronics and intelligent automation
- **Projects** with live demos and source code
- **Digital business card** that flips, plus a **Save contact** button that downloads a `.vcf` file for phones
- Responsive from phones to wide screens, keyboard accessible, and respects "reduce motion" settings
- No frameworks or build step: plain HTML, CSS and JavaScript

## 🗂️ Structure

```
index.html            Page content
assets/css/style.css  Styles (colours match my business card)
assets/js/main.js     Menu, typing effect, card flip, contact download, scroll animations
assets/img/logo.svg   HSN logo
```

## ✏️ Updating the site

Edit `index.html` and push to `main`. GitHub Pages republishes the site automatically within about a minute.
